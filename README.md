# Dota 2 Bservice

Landing page with a live MMR boost price calculator.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (for example `dota2-bservice`).
2. Upload `index.html` and `README.md` to the repository.
3. Go to Settings > Pages.
4. Under Source, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
5. After a minute, your site is live at `https://YOUR-USERNAME.github.io/dota2-bservice/`.
